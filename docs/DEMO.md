# ThermalETL — 30-second demo script

**Target length:** ~30 seconds  
**Format:** Screen recording + captions (no voice-over required)

---

## On-screen captions (timed)

| Time | Caption | Action on screen |
|------|---------|------------------|
| 0–3s | **ThermalETL — one clear fire history from two satellites** | Land on homepage; brand + map visible |
| 3–8s | **Pick a place** — draw on the map or type lat / lon | Type Warsaw coords or draw a small box; hex count updates |
| 8–14s | **See the fire calendar** — seasons & busy years at a glance | Pan to calendar; hover a cell; critical months outlined |
| 14–20s | **“Last month: 1.3× the usual median”** — plain language, not a forecast | Point at summary cards |
| 20–26s | **Local math, not one country-wide fudge factor** | Open /how-it-works; show hex-k vs regional diagram + validation % |
| 26–30s | **Free & open — NASA FIRMS data. Export CSV. Try it.** | Click CSV download; show footer disclaimer |

---

## Spoken version (optional, ~30s)

> “MODIS and VIIRS don’t count fires the same way — so history looks broken after 2012. ThermalETL stitches them into one series you can trust for a place you care about. Pick an area, see the season, the busy years, and how now compares with the usual median. No chatbot. No forecast. Just clear history from NASA FIRMS — free and open.”

---

## Recording tips

1. Use the sample region (default) so the demo works offline from the built site.
2. Prefer a 1280×720 or 1920×1080 window; hide personal bookmarks.
3. Enable captions burned-in (CapCut / iMovie / Descript) matching the table above.
4. End frame: live URL + “Not affiliated with or endorsed by NASA.”
