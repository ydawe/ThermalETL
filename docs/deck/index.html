The problem

Two satellites, two fire counts — trends break

  • MODIS (2000–, 1 km) and VIIRS (2012–, 375 m) count fires differently.
  • Raw stitch at 2012 looks like fires suddenly exploded — long-term trends are broken.
  • Existing tools are hard for ordinary people and often use one ratio per region.
ThermalETL2 / 7

The solution

Pick an area. Read the fire season in plain language.

  • Seasons, most active years, this period vs historical median.
  • CSV export for the selected area.
ThermalETL3 / 7

How it works

Local monthly coefficients, not one country fudge factor

FIRMS→ H3 hexes→ Monthly counts→ k(hex, month)→ Harmonized 2000–now→ Anomaly calendar
  • Per-hex, per-month VIIRS÷MODIS coefficient k.
  • Fallback: parent hex → wider area → region when support is thin.
  • Use VIIRS when present; else MODIS × k.

Next steps · Links

Wider coverage, more sensors, timely alerts

  • Global multi-country FIRMS layer (H3 res 4) alongside Poland.
  • More sensors: NOAA-20 / NOAA-21 VIIRS.
  • Optional alerts when a month exceeds the historical median.
  • Caveat: Poland 2002–2005 can show ~26–40k harmonized hotspots/yr vs ~5–9k later — partly real field burning, partly k≈9.4 amplifying MODIS-only years.
